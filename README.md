# M Shankarnath Portfolio
Plain HTML, CSS and JavaScript. No build step.

- Edit **js/data.js** to change links, resume, skills, projects, certificates, form endpoint and photo.
- Photo: add it to `assets/images/` and set `profilePhoto`.
- Resume: add the PDF to `assets/documents/` and set `resumeUrl`.
- Run locally: VS Code > Live Server > Go Live.
- Publish: GitHub Pages (Settings > Pages > Deploy from branch > main / root).
